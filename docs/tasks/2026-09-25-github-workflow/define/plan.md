# 计划：GitHub 工作流规范

- **Goal**：定义基于 Issue / Worktree / PR / Review Agent 的工作方式规范，取代「一切在单个会话内进行」的模式
- **Non-goals**：不绑定具体 review 工具；不改动协议与守则正文
- **Scope**：新增 `human/workflow.md`；`.github/` Issue 与 PR 模板；`agent/archive.md` 新增 GitHub 模式一节；README 更新；本任务档案
- **Constraints**：规范短、规则化；与协议/守则/档案的术语一一对应
- **Acceptance Criteria**：
  1. 原语映射表覆盖七个 GitHub 原语并与方法论概念对齐
  2. 反馈顺序、验收批量、并发限制、快速通道均有明确规则
  3. Issue 模板 = plan 字段，PR 模板 = 交付物清单
  4. 档案规则明确 GitHub 模式下任务目录只留 explore 与附件
- **Verification**：README 链接可达；模板字段与 templates/ 一致
