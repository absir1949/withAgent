# 计划：Agent 工作档案

- **Goal**：定义任务档案规则——Agent 工作过程的留痕、交接与经验沉淀方式
- **Non-goals**：不定义人的工作节奏（协议已覆盖）；不引入工具链
- **Scope**：新增《Agent 工作档案》；更新仓库 README；用本任务目录作为首个示例
- **Constraints**：写给 Agent 看，只留规则、保持短；标题与前三篇成系列；版本号放文末；路径一律英文
- **Acceptance Criteria**：
  1. 覆盖建档、归档、交接、经验与清理四类规则
  2. 入口文件与协议两个交接接口、守则 REVIEW 结论对齐
  3. 每条规则可被 Agent 直接执行，无解释性长文
- **Verification**：本任务目录即按该规则建立；README 链接可达
